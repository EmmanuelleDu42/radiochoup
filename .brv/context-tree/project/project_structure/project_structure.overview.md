### Key Points
- Adheres to standard Next.js App Router conventions.
- `app/` directory contains routing and page definitions.
- `components/` houses reusable UI elements.
- `hooks/` contains custom React hooks for encapsulated logic.
- `lib/` is reserved for utility functions and external service clients.
